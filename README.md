# Retail-Outlet-Performance-Mini-Project
## Overview
- Group academic project analyzing retail outlet performance
- Cleaned a messy dataset, explored it, and built a regression model

## Tools Used
- Python (pandas, NumPy, Matplotlib, Seaborn)
- R

## Key Findings
- Marketing spend is the strongest driver of monthly revenue (r = 0.91)
- Each extra $1 of marketing is linked to about $18.93 more revenue
- Marketing spend explains 82.5% of the variation in revenue (p < 0.001)
